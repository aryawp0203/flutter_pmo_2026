WIDGET KE DALAM FUNGSI
A. Capaian Pembelajaran
Setelah menyelesaikan praktikum ini, mahasiswa diharapkan mampu:
1. Membuat halaman form menggunakan widget TextField dan ElevatedButton.
2. Menggunakan widget SingleChildScrollView agar form dapat digulir.
3. Mengelompokkan berkas tampilan ke dalam folder ui.
4. Memisahkan widget ke dalam method/function tersendiri agar kode mudah dibaca dan
dikembangkan.
