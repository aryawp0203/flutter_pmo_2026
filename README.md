PERTEMUAN 6
NAVIGASI ANTAR HALAMAN DAN PENGIRIMAN DATA DENGAN NAVIGATOR
A. Capaian Pembelajaran
Setelah menyelesaikan praktikum ini, mahasiswa diharapkan mampu:
1. Membuat halaman detail yang dapat menerima data dari halaman lain.
2. Menggunakan TextEditingController untuk mengambil nilai dari TextField.
3. Melakukan perpindahan halaman menggunakan Navigator dan MaterialPageRoute.
4. Mengirimkan data dari halaman form ke halaman detail melalui parameter constructor.
