PERTEMUAN 7
MENAMPILKAN DATA DENGAN LISTVIEW, CARD, DAN PEMISAHAN WIDGET KE DALAM CLASS
A. Capaian Pembelajaran
Setelah menyelesaikan praktikum ini, mahasiswa diharapkan mampu:
Menampilkan daftar data menggunakan widget ListView, Card, dan ListTile.
Menambahkan tombol aksi pada AppBar menggunakan widget GestureDetector.
Memisahkan widget ke dalam class StatelessWidget tersendiri.
Membuka halaman detail ketika salah satu item pada daftar disentuh.
